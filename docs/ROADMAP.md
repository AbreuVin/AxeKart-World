# Roadmap — AxéKart

## v0.1 — protótipo (esta versão)
- [x] Pista procedural "Circuito de Teste do Axélab" a partir de `track.json`
- [x] Kart arcade: aceleração, freio/ré, grama lenta, barreira, drift com mini-turbo
- [x] Pilotos placeholder em sprite 8 direções (4 cores)
- [x] 3 CPUs, 3 voltas, contagem regressiva, posição, melhor volta, tela de chegada
- [x] Teclado e controle; testes headless; exportação Web 16:9

## v0.2 — identidade Axélab (próxima)
- [ ] Pilotos com arte própria (SpriteCook) seguindo o contrato de 8 direções
- [ ] Pistas temáticas: Pelourinho, Orla, Corredores do TJBA
- [ ] Relevo/rampas na pista
- [ ] Controles de toque no celular

## v0.3 — itens
- [ ] Caixas de item; carimbo (atordoa), pilha de processos (obstáculo),
      despacho urgente (turbo), toga (escudo)

## Depois
- [ ] Seleção de piloto e pista, campeonato, multiplayer local em tela dividida
- [ ] Trilha e efeitos sonoros próprios
- [ ] Publicação automática no GitHub Pages (como o Axé Fight)
